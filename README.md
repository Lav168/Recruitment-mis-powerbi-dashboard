# Recruitment MIS & Analytics Dashboard — Power BI

An interactive Power BI dashboard built to analyze recruitment performance, candidate pipeline, recruiter productivity, hiring requirements, and business insights.

## Project Overview

This project demonstrates how recruitment data can be transformed into an interactive MIS dashboard using Power BI.

The dashboard helps answer key business questions such as:

- How many candidates are in the recruitment pipeline?
- What is the candidate progression from submission to onboarding?
- Which recruiters have higher selection and onboarding performance?
- Which job roles have the highest hiring demand?
- Which locations have the highest candidate submissions?
- How many positions are filled versus still open?
- What recruitment trends can be observed over time?

## Dashboard Pages

### 1. Recruitment Overview

Provides a high-level view of the candidate pipeline, including:

- Total candidates
- Interviewed candidates
- Selected candidates
- Onboarded candidates
- Recruitment status distribution
- Monthly candidate submissions
- Submissions by job role
- Submissions by location

### 2. Recruiter Performance

Analyzes recruiter-level performance using:

- Candidate submissions
- Candidate selections
- Candidate onboardings
- Recruiter selection rate
- Interactive filters for client, job role, location, and month

### 3. Requirement Analytics

Analyzes hiring requirements and open positions through:

- Total requirements
- Total openings
- Filled positions
- Open positions
- Requirement status
- Openings by job role
- Filled vs. open positions
- Monthly requirement trends

### 4. Recruitment Insights

Summarizes key findings and business recommendations, including:

- Selection rate
- Onboarding rate
- Requirement fill rate
- Open position percentage
- Candidate pipeline insights
- High-demand roles
- Location opportunities
- Recruiter performance
- Recruitment improvement recommendations

## Data Privacy

This project uses **fully synthetic recruitment data created for portfolio demonstration purposes**.

No confidential candidate, recruiter, client, employee, or employer information is included.

The dataset contains fictional recruitment records created specifically for this project.
